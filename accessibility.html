Accessibility

I want this portfolio to be useful across devices, input methods, and accessibility needs.

The design target

This site is developed with WCAG 2.2 Level AA in mind. Automated checks support that work, but they are not a certification of full conformance.

Using the site

  • Use the skip link at the start of each page to move directly to the main content.
  • Navigation, project filters, and appearance controls work with a keyboard.
  • Text and layouts adjust to smaller screens and browser zoom.
  • Light and dark appearances use contrast-tested colors, and motion is reduced when requested by your device settings.
  • Page content, navigation, project links, and the contact form remain available without JavaScript.

Known limitations

The resume is an existing PDF and may not provide the same accessibility as the HTML pages. An HTML experience overview is available. The PDF viewer and Formspree’s submission pages are separate browser or third-party experiences.

Report a barrier

If something is difficult to use, please use the contact form. Include the page, what you were trying to do, and any relevant browser or assistive technology details so I can investigate.
