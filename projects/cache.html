LC2K Cache Simulator

  • C
  • Computer architecture

I built this simulator in C to explore how a cache handles memory reads and writes. It connects to an LC-2K processor simulator and supports different cache sizes and organizations, so I could compare how those choices affect memory access.

The project covers cache hits, misses, replacement, and writing modified data back to memory. I tested those behaviors with small programs that made each kind of memory access easy to follow.
