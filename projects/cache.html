Cache Simulator

This project involved building a configurable CPU cache simulator and integrating it into the LC-2K processor simulator used in courses teaching Computer Architecture. The simulator models real cache behavior and supports adjustable parameters such as block size, number of sets, and associativity.

  • Cache Design: Implemented direct-mapped, set-associative, and fully associative caches with LRU replacement and valid/dirty bit tracking.
  • Data Transfer: Simulated block-based transfers between memory and cache using write-back and allocate-on-write policies.
  • Integration: Extended the LC-2K processor simulator to call cache operations on every memory access, ensuring realistic execution behavior.
  • Debugging & Testing: Developed comprehensive test cases to validate correctness across cache configurations, including hits, misses, evictions, and write-backs.
  • Learning Outcome: Gained practical insight into the memory hierarchy and how cache organization impacts performance.
